# How to use profile_plotter.py
profile_plotter.py is a script to visualize the profiling command that should be enabled on each board. To use it make sure you do not have the serial port open in another program. Run the python script and select what port to read off of. 

The program will then run the profiling command and visualize the data at an interval of every 2 seconds. On exit the program will terminate system profiling.
